# TestOps Hub — resumo para currículo

- Desenvolvi uma plataforma TestOps de portfólio para centralizar e normalizar resultados automatizados provenientes do GitHub Actions, com histórico e rastreabilidade até workflow, artifact, branch e commit.
- Integrei execuções reais de Cypress/Mochawesome e Playwright JSON a uma API Fastify autenticada, usando adapters versionados e persistência transacional em PostgreSQL/Neon.
- Implementei métricas de qualidade, Execution Details, idempotência de ingestão e Regression Delta; a evidência pública inclui cenários 5/5, 5/5 e 4/5 com 1 nova falha detectada.
- Estruturei o projeto em TypeScript com React, Fastify, Docker, Render, Neon, GitHub Actions e testes unitários, de integração, E2E e produção.
