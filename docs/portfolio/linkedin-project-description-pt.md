# Descrição do projeto para LinkedIn

TestOps Hub é uma plataforma de portfólio que centraliza evidências de testes antes dispersas entre CI, reports, artifacts e logs. Execuções reais de Cypress e Playwright no GitHub Actions enviam relatórios a uma API Fastify autenticada; adapters normalizam os dados, o PostgreSQL/Neon persiste o histórico e o dashboard React apresenta métricas, rastreabilidade e Regression Delta. Evidência pública: 10 executados, 9 aprovados, 1 falha e 1 nova falha detectada. Dados fictícios e sintéticos.
