# TestOps Hub — 45–60 second demo script

Target length: approximately 55 seconds. Record the hosted interface without terminal, browser notifications, personal browser chrome, or local paths.

## 0–5s — Overview

**On screen:** Open the TestOps Hub Overview and pause on the title.<br>
**Voice-over:** “Automated test results, in one place.”

## 5–15s — Official metrics

**On screen:** Move to the official metric cards.<br>
**Voice-over:** “The latest official CI evidence shows 10 tests executed, 9 passed, 1 failed, and a 90% Quality Score.”

## 15–25s — Executions

**On screen:** Open Executions and point to the three official rows.<br>
**Voice-over:** “These results came from real GitHub Actions workflows: ShopSphere with Cypress and ServiceDesk with Playwright. Each run keeps its framework, branch, commit, and evidence source.”

## 25–40s — Functional failure and Regression Delta

**On screen:** Open the ShopSphere functional-failure execution, show 4 passed and 1 failed, then scroll to Regression Delta.<br>
**Voice-over:** “A previous ShopSphere execution passed five out of five. The next execution passed four out of five and introduced one functional failure. Regression Delta identifies it as one new failure.”

## 40–50s — How it works

**On screen:** Open How It Works and follow the pipeline from report to dashboard.<br>
**Voice-over:** “CI reports are authenticated, normalized through versioned adapters, persisted in PostgreSQL, and presented as traceable quality evidence.”

## 50–60s — Close

**On screen:** Show the GitHub repository beside the Live Demo URL, without opening private account menus.<br>
**Voice-over:** “TestOps Hub is a portfolio project focused on TestOps and Quality Engineering. The Live Demo and public evidence are available on GitHub.”

**End card:** `qualityops-hub.onrender.com` · `github.com/luanaabastos/testops-hub`<br>
**Disclaimer:** All products and data are fictional and synthetic.
